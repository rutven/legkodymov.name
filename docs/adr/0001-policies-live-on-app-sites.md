# Policies live on each App's own site

An App's privacy policy and Deletion page are published on the App's own domain (e.g. `ucisrpski.app/privacy`, `search.apartio.rs/privacy`) and this site only links to them; this site hosts a policy only for an App that has no site. Each App's backend already knows its real data handling and ships policy changes alongside behavior changes, and stores expect policy URLs tied to the App's listing — a central copy here would drift from the code it describes.
